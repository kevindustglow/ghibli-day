# 吉卜力公園親子日

Kevin 一家 2026/11 名古屋行的吉卜力公園當天手機引導頁。單一檔案 `index.html`，沒有 build 步驟。

## 怎麼改

| 想改什麼 | 在 `index.html` 找 |
|---|---|
| 日期、票種 | `const DAY = {...}` |
| 每一步的時間、標題、重點、是否計時 | `const STEPS = [...]`（`timer:true` 會出現倒數） |
| 日文名稱的中文翻譯 | `const GLOSS = {...}` |
| 出門清單 | `<ul class="chk">` |
| 路線圖站點 | `const NODES = [...]` |

存檔推上 `main`，GitHub Pages 約 1 分鐘後更新。

## 資料狀態（2026-10-22）

- 開園時間、休園日、票種、入場規則：已對照 ghibli-park.jp 官方網站。
- 地鐵與 Linimo 分鐘數：估計值，尚未對官方時刻表。
- 路線圖是順序示意，非實際位置。

個人旅行筆記，非官方資訊。

## 地圖與離線

- 所有地圖、時刻表都放在 `maps/`，不外連其他網站。
- `sw.js` 會在第一次開啟後，把頁面和地圖存進手機；園區沒網路也能看。新增或換圖時，記得同步改 `sw.js` 的 `FILES` 清單，並把 `V` 版本號加一。

## 八日行程頁 `trip/`

整趟旅程（台灣家門口 → 名古屋 8 天 → 回到家）的手機頁：https://kevindustglow.github.io/ghibli-day/trip/ 。單一檔案 `trip/index.html`。

| 想改什麼 | 在 `trip/index.html` 找 |
|---|---|
| 每天的時間、行程、看情況、吃的、交通 | `const DAYS = [...]`（`rg` 去程、`rb` 回程） |
| 還沒買、出發前 7 天、行李清單 | `TODO_BUY`、`TODO_WEEK`、`PACK` |
| 飯店、航班、接送、車資、緊急電話、連結 | `const INFO = {...}` |

勾選只存在各自手機裡。公開頁面不放訂位代號、票券連結、座位、住址、司機與保單資料。資料以 Google 文件 2026/10/27 總覽表為準；車資查證日 2026/10/28。
